# PharmaPrice Lens

수출입 단가 협상 코파일럿. 상대가 제시한 단가를 **UN Comtrade 공식 무역통계**와 비교해 시장 분포 속 위치를 판정하고, 다시 제안할 가격과 근거, 영문 회신 메일까지 만들어 줍니다.

KITA 무역 AX마스터 프로젝트 · 제작: 최가은

## 주요 기능

| 화면 | 하는 일 |
|---|---|
| 품목·국가 검색 | HS 2022 코드 6,939개를 한글·영문·코드로 검색, UN Comtrade 보고국 200여 개 선택 |
| 시장 대시보드 | 물량 가중 평균 단가, 최근 변동, 물동량, 최대 공급국, 집중도(HHI), 자동 시장 신호 |
| 국가별 단가 | 상대국별 단가·물동량·점유율·변동 정렬, 소량 거래국 표시, CSV 내려받기 |
| 추이 분석 | 최대 4개국 단가·물동량 추이, 3기간 이동평균, 변동성(CV) |
| 교역 루트맵 | 세계 지도 위 교역 루트(선 굵기=물량, 색=평균 대비 단가) |
| 협상 코파일럿 | 제시가 판정(5단계), 비교 신뢰도, 가격 외 확인 항목(등급·GMP·DMF/CEP·유효기간·콜드체인 등), 환산 과정, 1차 제시가·목표가·마지노선, 합의 효과, 협상 근거, 영문 메일, 보고 메모, AI 문장 다듬기 |
| 견적 비교 | 조건·통화·결제 기간이 다른 견적 최대 8개를 같은 기준으로 순위 |
| 수출 마진 계산기 | 원가·환율·목표 마진으로 견적가 계산, 대상국 시장 단가와 비교 |
| 협상 기록 | 저장·다시 열기·CSV 내려받기 |
| 데이터 관리 | 실시간 / 업로드 CSV / 예시 데이터 전환, 관세청·Comtrade CSV 자동 인식 |

한국어·영어 화면 전환을 지원합니다.

- **환율**: ExchangeRate-API의 무료 공개 환율(하루 1회 갱신)을 자동으로 불러와 USD·EUR·KRW·CNY·JPY·INR·CHF·GBP 견적을 환산합니다. 직접 입력한 환율은 유지되고, "최신 환율로 되돌리기"로 다시 받을 수 있습니다. 연결되지 않으면 2026-10-18 기준 환율을 씁니다.
- **현지어 병기**: 영문 메일을 원본으로 두고, 상대국 언어(중국어·일본어·베트남어·스페인어 등 15개)로 AI 번역본을 함께 만들 수 있습니다. 번역본의 숫자가 영문과 다르면 경고합니다. (AI가 연결된 경우에만)
- **상대국 통계 교차 확인(미러 데이터)**: 같은 거래를 상대국이 신고한 단가와 비교해 이 나라 단가를 근거로 써도 되는지 알려줍니다. 예: 한국의 중국산 그 밖의 항생물질(294190) 2024년 수입 CIF $127.9/kg vs 중국 신고 수출 FOB $111.3/kg → 1.15배, 운임·보험료 범위로 일치.
- **소개 화면 미디어**: 각 화면의 실제 조작 녹화 GIF 7개와 직접 그린 일러스트(교역 루트 지도, 로그인 화면 그림)가 들어 있습니다.

## 계산 방법 요약

- 단가 = 신고금액 합 ÷ 순중량 합 (스마트폰·자동차처럼 개수가 맞는 품목은 보조 수량 단위로 계산)
- 수입은 CIF 금액(없으면 FOB), 수출은 FOB 금액 사용
- 시장 분포 = 국가×기간 단가를 물량으로 가중한 P10·P25·중앙값·P75·P90
- 제시가는 시장 **중앙값** 대비 %로 표시(고가 제품 몇 건이 평균을 끌어올리는 의약품 특성 반영), 가중평균도 함께 표시
- 판정 = 제시가 이하에서 거래된 물량 비율
- 기간: UN Comtrade가 해당 보고국 자료를 실제 공개한 최신 기간부터 N개(공개 지연이 크면 화면에 안내)
- 최근 단가 변동 = 같은 나라끼리 비교(두 기간 중 작은 물량으로 가중). 싼 나라·비싼 나라 비중이 바뀌어 생기는 평균 변화(구성 효과)는 따로 표시. 예: 한국 비타민 C 수입(2025년 실제 자료)에서 전체 평균은 −18.9%였지만 나라별로는 −0.9%였고, 차이는 고가인 영국산 물량 감소 때문
- 거래가 없는 달은 그래프에서 빈 구간으로 표시
- 조건 환산(인코텀즈 2020, 11개 조건): 모든 조건을 FOB(=FCA·FAS)로 바꾼 뒤 통계 기준으로 다시 계산
  - CFR·CPT = FOB + 운임(FOB 대비 % 또는 USD/kg)
  - CIF·CIP = CFR ÷ (1 − 1.1 × 보험료율) — 계약금액 110% 부보 규칙
  - EXW = FOB ÷ (1 + 수출지 비용%), DAP·DPU = CIF × (1 + 도착지 비용%), DDP = DAP + CIF × 관세율%(관세는 CIF 과세가격 기준, 부가세 제외)
- 비교 신뢰도(높음·보통·낮음): 관측치 수, 가격 폭(P90/P10), 4자리·"그 밖의" 코드, 30류 의약품 한계·이전가격, 주요 상대국 수, 추정 중량 비중으로 판단. 낮음이면 판정을 참고용으로 표시하고 메일에 구체적 %를 쓰지 않음
- 30류 의약품은 kg당 판매단위 수(도즈 또는 팩)를 넣어 판매단위당 가격으로도 비교
- 29류 중 의약품 관련 호(2936~2942)와 주요 원료는 자동으로 의약품 모드, 그 밖의 29류 코드는 "의약품 원료(API)로 보기"로 켤 수 있음
- 견적 비교는 결제 기간(선급은 −일)을 연 이자율로 할인해 반영
- 협상 문구와 메일은 계산 결과에 따른 규칙으로 생성. AI는 사용자가 원할 때 문장만 다듬고, 숫자가 바뀌면 경고

## 배포하기 (GitHub + Vercel, 약 10분)

코딩이나 설치 없이 웹사이트에서 클릭만으로 할 수 있습니다.

### 1. GitHub에 올리기

1. [github.com](https://github.com)에 로그인하고 오른쪽 위 **+** → **New repository**를 누릅니다.
2. Repository name에 `pharmaprice-lens`를 입력하고 **Public**을 고른 뒤 **Create repository**를 누릅니다.
3. 새 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 압축을 푼 `pharmaprice-lens` 폴더 **안의 내용물 전부**(index.html, package.json, README.md, api·data·assets 폴더)를 끌어다 놓습니다.
   - 폴더째 올리면 주소가 `/pharmaprice-lens/index.html`처럼 한 단계 깊어지니, 꼭 **안의 내용물**을 올리세요.
5. 아래 **Commit changes**를 누릅니다.

### 2. Vercel로 배포하기

1. [vercel.com](https://vercel.com)에서 **Continue with GitHub**로 로그인합니다.
2. **Add New… → Project**를 누르고 `pharmaprice-lens` 저장소 옆 **Import**를 누릅니다.
3. Framework Preset은 **Other** 그대로 두고 **Deploy**를 누릅니다.
4. 1분쯤 뒤 `https://pharmaprice-lens-xxxx.vercel.app` 주소가 생깁니다.

### 3. 확인하기

1. 주소로 들어가 **데모 계정으로 둘러보기**를 누릅니다.
2. 화면 위쪽 배지에 초록 점과 함께 **UN Comtrade 실시간**이 보이면 성공입니다.
3. 처음 조회는 기간마다 한 번씩 요청해서 10~20초 걸릴 수 있습니다. 한 번 불러온 자료는 24시간 저장됩니다.

### 4. (선택) 더 안정적으로 쓰기

Vercel 프로젝트 → **Settings → Environment Variables**에서 아래 값을 넣고 **Deployments → 최신 배포 → Redeploy**를 누릅니다.

| 이름 | 하는 일 | 받는 곳 |
|---|---|---|
| `COMTRADE_KEY` | 정식 API 사용: 500행 제한 해제, 한 번에 최대 12개 기간 조회(호출 약 1/12), 운송 수단별(항공·해상) 선택(지원 보고국만) | [comtradedeveloper.un.org](https://comtradedeveloper.un.org)에서 가입 후 무료 구독 키 발급 |
| `ANTHROPIC_API_KEY` | 배포 사이트에서 "AI로 다듬기"·"AI로 번역" 버튼 사용 (사용량만큼 요금 발생) | [console.anthropic.com](https://console.anthropic.com) |
| `ANTHROPIC_MODEL` | AI 모델 이름을 바꿀 때만 (기본값 `claude-sonnet-5-5`) | |

키가 없어도 실시간 조회와 나머지 기능은 모두 동작합니다.

> **ANTHROPIC_API_KEY를 넣는다면** Anthropic Console에서 이 키의 월 사용 한도(spend limit)를 꼭 정해 두세요. 사이트는 같은 사이트에서 온 요청만 받고, IP당 10분에 20회로 제한하며, 메일 형식("Subject:"로 시작) 문장만 처리하지만, 공개 사이트인 만큼 한도 설정이 가장 확실한 안전장치입니다.

## 데이터 출처와 라이선스

- 무역통계: [UN Comtrade](https://comtradeplus.un.org) (UN 통계처). 이용 조건은 UN Comtrade 약관을 따릅니다.
- HS 2022 품목표: WCO, [datasets/harmonized-system](https://github.com/datasets/harmonized-system) (ODC-PDDL)
- 국가 이름: [stefangabos/world_countries](https://github.com/stefangabos/world_countries)
- 국가 중심 좌표: [gavinr/world-countries-centroids](https://github.com/gavinr/world-countries-centroids)
- 세계 지도: [johan/world.geo.json](https://github.com/johan/world.geo.json) (Unlicense)
- 환율: [Rates By Exchange Rate API](https://www.exchangerate-api.com) — 무료 공개 엔드포인트, 하루 1회 갱신, 화면에 출처 표기
- 소개 화면 GIF는 이 앱을 예시 데이터로 직접 녹화한 것이고, 일러스트는 직접 그린 SVG입니다(지도 윤곽만 위 world.geo.json 사용)
- 한글 품명: 류(2자리) 전체, 29류 호 전체, 의약품 관련 소호(2936~2942, 3001~3006)와 주요 품목 등 420여 개를 직접 정리. 나머지는 영문 공식 품명 표시

한국 비타민 C(293627) 2025년 3~9월 월간 실제 자료로 최근 변동·구성 효과·국가별 변동 계산도 대조해 일치를 확인했습니다.

이 실제 데이터 각각에 인코텀즈 11개 × 통화 4개 × 제시가 5단계(중앙값의 0.3~3배)를 넣어 2,200여 경우를 자동 점검했습니다. 환산 정확도, 1차·목표·상한 가격 순서, 메일 문장 방향(높다/낮다), 판정 순위가 모두 맞았습니다.

품목 검색은 성분명·제품군 34개(아목시실린, 세프트리악손, 인슐린, 덱사메타손, 바이오시밀러, 보툴리눔 등)로 시험해 모두 맞는 HS 코드를 상위 3위 안에 찾았습니다.

## 실무에서 더 정확하게 쓰는 법

- **한국 수출입이면 관세청 10단위 자료를 쓰세요.** 관세청 수출입무역통계(tradedata.go.kr)에서 품목별·국가별 실적을 HSK 10단위로 내려받아 "데이터 관리"에 올리면, 6자리 HS보다 성분에 가깝고 UN Comtrade보다 최신인 단가로 비교합니다. 품목명 열도 함께 읽고, 여러 품목이 있으면 눌러서 바꿀 수 있습니다.
- **UN Comtrade는 공개까지 수개월 늦습니다.** 2026년 10월 기준 한국 월간 자료는 2025년 12월까지 공개돼 있습니다.

## 안정성

- 외부 조회는 모두 시간 제한이 있어 응답이 없으면 멈추지 않고 안내합니다(서버 함수 최대 60초).
- 일부 기간만 실패하면 나머지로 계산하고 "다시 불러오기"를 보여줍니다. 오류 응답은 캐시하지 않습니다.
- 브라우저 저장 공간이 차지 않도록 실시간 자료는 최근 6개 조회만 보관합니다. 저장값이 깨져도 기본값으로 시작합니다.
- CSV는 BOM·따옴표 안 쉼표·세미콜론+소수점 쉼표·여러 보고국·운송수단별 세부 행·엑셀에서 앞자리 0이 빠진 코드까지 처리합니다.

## 의약품 데이터를 볼 때 주의할 점

- 원료의약품(대부분 29류)은 같은 6자리 코드 안에도 성분·등급(USP·EP·JP)·멸균 여부가 섞입니다. 예: 294190에는 세팔로스포린, 반코마이신 등 여러 항생물질이 함께 들어 있습니다.
- 완제의약품(3004)과 바이오의약품(3002)은 제품·함량이 다르고 순중량에 내포장이 일부 포함돼 kg당 단가가 거칩니다.
- 의약품 수입에는 다국적 제약사 본사-지사 간 이전가격 거래가 많습니다.
- 등록된 의약품은 공급처를 바꾸려면 허가 변경(보통 6~18개월)이 필요해, 대체 공급처 견적의 협상력이 제한될 수 있습니다.
- 2022년 HS 개정으로 3002 등 일부 코드가 바뀌어 그 전 연도 자료는 다를 수 있습니다.

## 한계

통관 단가는 품질 등급, 포장 단위, 계약 시점, 관계사 간 거래가, 운송 수단(해상·항공)을 구분하지 않습니다. UN Comtrade는 일부 중량을 추정하며, 보고국과 상대국의 수치가 다를 수 있습니다. 협상의 기준점으로 쓰고 최종 판단은 실제 견적과 함께 하세요.
